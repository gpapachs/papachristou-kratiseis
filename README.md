# Κρατήσεις — Ψητοπωλείο Παπαχρήστου (v1.5.1)

Εφαρμογή διαχείρισης κρατήσεων για το προσωπικό. Δουλεύει στα ταμεία (PC) και στα κινητά, και όλες οι συσκευές βλέπουν τις ίδιες κρατήσεις ζωντανά.

## Τι κάνει
- **Λίστα ημέρας**: κρατήσεις ανά ώρα, κουμπιά «Ήρθε / Δεν ήρθε / Έφυγε», αναζήτηση, εκτύπωση.
- **Φόρτος ανά ώρα**: μπάρες με τα άτομα στο μαγαζί σε κάθε μισάωρο σε σχέση με το μέγιστο.
- **Κάτοψη**: οι χώροι σου (σάλα, αυλή…) με τα τραπέζια στη θέση τους. Διαλέγεις ώρα και βλέπεις ποια είναι ελεύθερα, κρατημένα, κρατημένα σε λίγο ή πιασμένα. Πάτημα σε ελεύθερο τραπέζι = νέα κράτηση· σε κρατημένο = άνοιγμα της κράτησης. Οι κρατήσεις χωρίς τραπέζι ανατίθενται με δύο πατήματα.
- **Σχεδιαστής κάτοψης** (Κάτοψη → Επεξεργασία ή Ρυθμίσεις → Χώροι & τραπέζια): πολλοί χώροι, τραπέζια τετράγωνα/στρογγυλά/μακρόστενα με καρέκλες, μετακίνηση με σύρσιμο, αλλαγή μεγέθους, περιστροφή, τοίχοι, παράθυρα, πόρτες, μπαρ/πάγκοι, φυτά, χρωματιστές ζώνες και κείμενα. Αναίρεση με Ctrl+Z.
- **Ένωση τραπεζιών**: στην Κάτοψη πατάς «Ένωση», διαλέγεις τα τραπέζια και τα κάνεις νέα κράτηση ή τα δίνεις σε υπάρχουσα (με έλεγχο αν είναι ελεύθερα). Τα ενωμένα τραπέζια φαίνονται συνδεδεμένα στην κάτοψη και με ⛓ στη λίστα και στο χρονοδιάγραμμα.
- **Χρονοδιάγραμμα**: γραμμή ανά τραπέζι και χώρο. Πάτημα σε κενό σημείο = νέα κράτηση εκεί.
- **Αυτόματη ανάθεση**: βρίσκει το μικρότερο ελεύθερο τραπέζι που χωράει την παρέα, αλλιώς ενώνει τα πιο κοντινά τραπέζια στην κάτοψη.
- **Χρήστες**: σύνδεση με όνομα χρήστη και κωδικό. Δύο ρόλοι: **Διαχειριστής** (τα πάντα) και **Προσωπικό** (κρατήσεις, κάτοψη, μηνύματα — όχι ρυθμίσεις/χρήστες). Τους χρήστες τους φτιάχνει ο διαχειριστής από Ρυθμίσεις → Χρήστες και στέλνει τα στοιχεία με Viber/WhatsApp/SMS. Κάθε χρήστης αλλάζει τον κωδικό του από το εικονίδιό του πάνω δεξιά. Τα δικαιώματα ελέγχονται και από τη βάση.
- **Εμφάνιση**: 10 χρωματικά θέματα και φωτεινό / σκοτεινό / αυτόματο. Ισχύει ανά συσκευή ή για όλες.
- **Έλεγχοι**: προειδοποιεί για κλειστή μέρα, εκτός ωραρίου, υπέρβαση χωρητικότητας, πιασμένο τραπέζι.
- **Ιστορικό πελάτη**: με το τηλέφωνο δείχνει προηγούμενες κρατήσεις, σημειώσεις και πόσες φορές δεν ήρθε.
- **Μηνύματα**: επιβεβαίωση / υπενθύμιση / ακύρωση με ένα πάτημα σε SMS, Viber, WhatsApp ή email. Η καρτέλα «Μηνύματα» δείχνει τι εκκρεμεί.
- **Ειδικές μέρες**: για συγκεκριμένη ημερομηνία ορίζεις «Κλειστά» ή «Ειδικό ωράριο» (π.χ. Τρίτη που ανοίγετε από το πρωί). Εκείνη τη μέρα ισχύει μόνο αυτό και φαίνεται σήμα ★ πάνω από τις κρατήσεις.
- **Ρυθμίσεις**: ωράριο ανά μέρα (έως 3 βάρδιες), ειδικές μέρες, τραπέζια, χωρητικότητα, κείμενα μηνυμάτων.

## Δοκιμή χωρίς εγκατάσταση
Άνοιξε το `index.html` με `?demo` στο τέλος της διεύθυνσης (ή πάτα «Δοκιμαστική λειτουργία» στην αρχική). Τα δεδομένα μένουν μόνο στον browser.

## Αναβάθμιση από v1.0 / v1.1
1. Supabase → **SQL Editor** → τρέξε ξανά **ολόκληρο** το νέο `schema.sql` (δεν σβήνει τίποτα). Τα παλιά τραπέζια μπαίνουν στους χώρους «Μέσα» και «Έξω».
2. Ανέβασε στο GitHub όλα τα αρχεία (νέα: `floor.js`, `theme.js`, `manifest.webmanifest`, `sw.js`, φάκελος `icons`). **Μην** αντικαταστήσεις το `config.js` σου.
3. Άνοιξε **Κάτοψη → Επεξεργασία κάτοψης**, σύρε τα τραπέζια στη θέση τους και πάτα **Αποθήκευση**.

## Εγκατάσταση (μία φορά)

### 1. Supabase
Μπορείς να χρησιμοποιήσεις το ίδιο Supabase project με το site παραγγελιών (οι πίνακες έχουν άλλα ονόματα) ή ένα καινούργιο.
1. **SQL Editor → New query** → επικόλλησε όλο το `schema.sql` → **Run**.
2. **Authentication → Sign In / Providers** → κλείσε το **Allow new users to sign up** (για να μη μπορεί να γραφτεί ο καθένας).
3. **Πρώτος διαχειριστής**: στο SQL Editor, νέο query, γράψε (με δικό σου όνομα χρήστη/κωδικό) και πάτα **Run**:
   ```sql
   select public.admin_bootstrap('giorgos', 'ο-κωδικός-σου', 'Γιώργος');
   ```
   Όλους τους άλλους χρήστες τους φτιάχνεις μετά μέσα από την εφαρμογή (Ρυθμίσεις → Χρήστες).
4. **Project Settings → API**: αντέγραψε το **Project URL** και το **anon public** κλειδί.

### 2. config.js
Άνοιξε το `config.js` και βάλε τα δύο στοιχεία:
```js
SUPABASE_URL: 'https://xxxx.supabase.co',
SUPABASE_ANON_KEY: 'eyJ...'
```

### 3. GitHub + Vercel
1. Στο GitHub: **New repository** (π.χ. `papachristou-kratiseis`) → **Add file → Upload files** → σύρε όλα τα αρχεία του φακέλου → **Commit**.
2. Στο Vercel: **Add New → Project** → διάλεξε το repo → Framework Preset: **Other** → **Deploy**. Δεν χρειάζεται build.
3. Σε κάθε αλλαγή αρχείων στο GitHub, το Vercel ανανεώνει μόνο του το site.

### 4. Εγκατάσταση ως εφαρμογή
- **Android / PC (Chrome, Edge):** άνοιξε τη διεύθυνση και πάτα το κουμπί **Εγκατάσταση** πάνω δεξιά (ή μενού ⋮ → «Εγκατάσταση εφαρμογής»).
- **iPhone / iPad:** άνοιξε στο Safari → Κοινοποίηση → «Προσθήκη στην οθόνη Αφετηρίας».
- Ανοίγει σε πλήρη οθόνη με δικό της εικονίδιο. Συντόμευση «Νέα κράτηση» με παρατεταμένο πάτημα στο εικονίδιο (Android).

## Αρχεία
| Αρχείο | Τι είναι |
|---|---|
| `index.html` | Η σελίδα |
| `app.js` | Η εφαρμογή (οθόνες, φόρμες, ρυθμίσεις) |
| `floor.js` | Κάτοψη και σχεδιαστής χώρων |
| `theme.js` | Χρωματικά θέματα |
| `logic.js` | Ωράριο, χωρητικότητα, ανάθεση τραπεζιών, μηνύματα |
| `store.js` | Σύνδεση με Supabase / δοκιμαστική λειτουργία |
| `styles.css` | Εμφάνιση |
| `config.js` | Στοιχεία Supabase |
| `manifest.webmanifest`, `sw.js`, `icons/` | Εγκατάσταση ως εφαρμογή (εικονίδιο, πλήρης οθόνη) |
| `schema.sql` | Πίνακες της βάσης (τρέχει μία φορά, και ξανά σε κάθε αναβάθμιση) |

## Σημειώσεις
- Ώρες μετά τα μεσάνυχτα (π.χ. 00:30) μετράνε στην ίδια βάρδια της προηγούμενης βραδιάς.
- Αν αλλάξει μέρα ή ώρα σε μια κράτηση, η επιβεβαίωση/υπενθύμιση ξαναμπαίνει στις εκκρεμότητες.
- Τα μηνύματα στέλνονται από τη συσκευή (δεν υπάρχει κόστος). Αυτόματα SMS χωρίς πάτημα θέλουν πάροχο SMS — μπορεί να προστεθεί αργότερα.
